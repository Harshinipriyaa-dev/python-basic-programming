# Python Basic Programming 🐍

A collection of foundational Python projects and data structure experiments built during my 11th and 12th standard. This repo tracks my journey learning core programming logic, algorithms, and problem-solving without relying on AI tools.

## 🛠️ Featured Projects

* *Expense Tracker (expense_tracker.py):* A command-line application to log, track, and manage daily expenses.
* *Password Generator (password_generator.py):* Generates secure, randomized passwords based on custom user constraints.
* *Hangman Game (game_hangman.py):* A classic word-guessing game logic built entirely using python strings and loops.
* *Coin Exchange (coin_exchange.py):* Not implementation of a basic greedy algorithm to find the minimum number of coins needed for a given amount but my own logic ( I know it is not DSA move but I tried it before I Knew wht is DSA)
